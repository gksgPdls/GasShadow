기술무엇인가우리 시스템에서
RAG먼저 뜻이 비슷한 근거를 찾고, 그 근거로 LLM이 답하게 하는 방식경보가 뜨면 판례집에서 비슷한 과거 처리 기록·사고 사례·법 조문을 찾는다 (②-2)
LangGraphAI 작업 순서를 짜고 진행하는 도구②의 1→5 순서를 진행한다. 추천이 이상하면 다시 쓰게 하고, 관리자 승인까지 멈춰 기다린다
OpenRouter (LLM)글을 쓰는 AI. OpenRouter는 여러 LLM을 키 하나로 쓰게 해주는 창구RAG가 찾은 근거로 조치 순서와 이유를 쓴다 (②-3). 나중에 사내 모델로 교체 가능
5가스 위험예측우리가 직접 학습시킨 예측 모델 (scikit-learn)기준 초과 전에 미리 경고한다 (①)
PostgreSQL + pgvector데이터베이스 + "뜻이 비슷한 글" 검색 기능센서 값·경보·처리 기록을 저장하는 판례집. RAG 검색도 여기서 한다
FastAPI파이썬 서버 도구메인 서버(규칙 판정·경보)와 AI 서버
