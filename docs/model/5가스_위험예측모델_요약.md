# 5가스 위험예측 모델 요약

## 무엇을 예측하는가

최근 최대 40분의 O₂·LEL·CO·H₂S·CO₂ 측정값과 작업 종류·작업 상태를 이용해 다음을 예측한다.

- 30분 안에 법정 기준을 넘을 위험 확률
- 60분 안에 기준을 넘을 것으로 예상되는 가스
- 기준까지 남은 예상 시간
- 최종 상태: `STABLE` / `WATCH` / `IMMINENT`

현재 측정값이 이미 법정 기준을 넘었거나 센서 값이 유효하지 않으면 모델이 추측하지 않는다. 현재 초과는 규칙으로 즉시 경보하고, 결측·통신 두절은 `UNAVAILABLE`로 처리한다.

## 사용한 데이터와 모델

- 데이터: 5가스 합성 시계열 1,259개 시나리오, 380,917행, 15초 간격
- 입력: 5가스 값, 작업 종류, 작업 상태, 측정 품질
- 학습 단위: 같은 시나리오가 학습·검증·시험에 섞이지 않도록 시나리오 단위 분리
- 모델 구성: 30분·60분 위험 분류, 위험 가스 분류, 기준 도달시간 회귀
- 비교 기준: 최근 가스 상승 추세를 단순 연장하는 선형 기준선

## 시험 결과

| 항목 | 선형 기준선(10분) | 최종 모델 |
|---|---:|---:|
| 30분 위험 Recall | 0.319 | 0.800 |
| 30분 위험 Precision | 0.218 | 0.368 |
| 30분 위험 F1 | 0.259 | 0.504 |
| 위험 가스 Macro F1 | 0.315 | 0.406 |
| 기준 도달시간 MAE | 7.88분 | 7.03분 |
| 평균 선행시간 | 8.4분 | 23.8분 |

모델은 기준선보다 위험을 더 일찍, 더 많이 탐지했다. 다만 정밀도가 0.368이고 정상 작업에서도 경보가 자주 발생해, 현재 결과를 현장 성능으로 해석하면 안 된다.

## 반드시 함께 설명할 한계

- 학습과 평가는 모두 합성 데이터로 수행했다.
- 합성 데이터의 위험 발생 비율과 상승 형태가 실제 현장과 다를 수 있다.
- 실제 현장 데이터를 확보하면 다시 학습하고 임계값을 조정해야 한다.
- 모델은 작업 중지·대피를 결정하지 않는다. 법정 기준 초과 경보는 규칙이 담당하고 최종 조치는 안전관리자가 결정한다.
